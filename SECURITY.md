# Security

Please report vulnerabilities **privately** via
[GitHub: Report a vulnerability](https://github.com/vinctdev/SkyTripwire/security/advisories/new), not as a public issue.

Only the latest release gets fixes.

Keep in mind: SkyTripwire has no login by design. Exposing it to the internet without a
reverse proxy with authentication or a VPN is a setup issue, not a vulnerability.
